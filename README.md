# 📊 Sample Superstore Data Analysis

## 📌 Project Overview

This project focuses on analyzing the **Sample Superstore Dataset**, which contains transactional data of a retail business. The dataset includes information related to sales, profit, customer segments, regions, product categories, and discounts.

The goal of this project is to extract meaningful insights from the data and understand business performance to support better decision-making.

---

## 🎯 Objectives

* Analyze overall **sales and profit performance**
* Identify **top-performing and loss-making categories**
* Evaluate **regional and state-wise performance**
* Understand **customer segment contribution**
* Analyze the impact of **discounts on profitability**
* Detect patterns in **high sales but low profit scenarios**

---

## 🛠️ Technologies Used

* Python 🐍
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## 📂 Dataset Information

* Total Records: **9994**
* Total Columns: **13**
* Key Columns:

  * Sales
  * Profit
  * Discount
  * Category & Sub-Category
  * Region & State
  * Segment

---

## 📊 Key Analysis Performed

* Category & Sub-Category Analysis
* Region & State Analysis
* Segment-wise Analysis
* Discount vs Profit Analysis
* Correlation Analysis (Sales vs Profit)
* Profit Margin Analysis
* Visualization using charts (Bar, Pie, Scatter, Heatmap)

---

## 🔍 Key Insights

* High discounts often lead to **low or negative profit**
* Some sub-categories generate **high sales but low profit**
* Certain regions perform better in terms of **profit margins**
* Customer segments contribute differently to revenue
* Profitability depends on both **pricing and discount strategies**
